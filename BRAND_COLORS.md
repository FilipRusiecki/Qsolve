# QSolve brand colours

From the QSolve brand book (`_brandbook_work/brandbook.html`).

| Token | Hex | Use |
|-------|-----|-----|
| `qs-black` | `#000000` | Primary dark / logo lockups |
| `qs-ink` | `#111111` | Body text on light |
| `qs-green` | `#0B8005` | Primary brand accent |
| `qs-gold` | `#DBC06F` | Secondary accent / highlights |
| `qs-paper` | `#FFFFFF` | Light surfaces |
| `qs-muted` | `#6B7280` | Secondary text |

## Type

- Display / headings: **Montserrat** (variable)
- Body: **Work Sans** (variable)
